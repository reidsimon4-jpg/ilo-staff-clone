# Blocky Buccaneers

Small browser pirate game with a blocky look. Open `index.html` in any browser (no install, no build).

- **Sail:** W A S D / arrow keys
- **Fire:** Q (left side), E (right side), Space (both sides)
- **Mute:** M
- **Phone:** joystick on the left, FIRE L / FIRE R buttons

Sink the enemy ships, collect coins and treasure chests, and survive the waves.

Code: `world.js` (map, islands, pickups), `entities.js` (ships, cannons, AI), `ui.js` (HUD, menus, input, sound), `main.js` (game loop). Interface spec: `CONTRACT.md`.
